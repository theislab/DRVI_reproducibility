# MichiGAN

This directory contains the implementations of the **MICHIGAN** and **BTCVAE** models.

## Background

This implementation is based on the original MichiGAN repository: [welch-lab/MichiGAN](https://github.com/welch-lab/MichiGAN).

## Modifications

Compared to the original repository, the following updates have been made for this reproducibility package:
- Added a convenient Python interface to easily train and evaluate models from Python scripts.
- Updated the codebase to be fully compatible with TensorFlow 2.x (running in graph/v1 compatibility mode).
- Verified that the output and performance remain identical to the original implementation.
